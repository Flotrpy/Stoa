# UI design rationale

The desktop uses a restrained enterprise-security visual system with only light and dark modes.
The final pass drew on established patterns rather than mimicking a specific product:

- Carbon's data-table guidance informed stable headers, compact rows, visible selection, and the
  convention that search/filter/export actions belong together above result sets.
- PatternFly's empty-state guidance informed concise state explanations paired with one clear next
  action instead of decorative placeholder content.
- Material dark-theme guidance informed charcoal surfaces instead of pure black, desaturated
  accent colors, and legible contrast across elevations.

Stoá uses Segoe UI/Inter fallbacks, an eight-pixel spacing rhythm, restrained teal status/action
color, strong focus rings, consistent field and table treatment, sentence-case labels, and no
decorative gradients, glass effects, generated illustrations, or excessive rounded cards.
