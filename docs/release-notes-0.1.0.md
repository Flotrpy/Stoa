# Stoá 0.1.0 release notes

Initial review release of the unified defensive-security workspace for Windows and Linux. It
includes identity/RBAC, endpoint enrollment, authorized port and web scanning, packet analysis and
IDS, firewall simulation, file-integrity monitoring, process-risk indicators, phishing analysis,
the offline password lab, and ciphertext-only encrypted team chat.

This is not a production-certified release. Required external evidence still includes independent
cryptographic review, organization code-signing, clean-machine installer verification, and a
production PostgreSQL backup/restore drill. See `STATUS.md` for exact automated evidence and
residual risks.
